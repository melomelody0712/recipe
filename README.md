# レシピ管理アプリ

> Web開発の練習として作成したアプリです。

**デモ：** https://melomelody0712.github.io/recipe/recipe.html

ブラウザだけで動くレシピ管理Webアプリです。バックエンド不要・ライブラリ不使用のバニラJavaScriptで実装しました。

## 機能

- **レシピの登録・編集・削除**　レシピ名・材料・調味料・手順を管理
- **ドラッグ＆ドロップ並び替え**　一覧をドラッグ操作で並び替え可能
- **プレビュー表示**　登録済みレシピをカード形式でリアルタイム表示
- **印刷対応**　全レシピまたは選択したレシピをA4横向き2段組でレイアウトして印刷
- **バックアップ機能**　レシピデータをJSONファイルとしてエクスポート・インポート
- **データ永続化**　LocalStorage を使ってブラウザにデータを保存

## 使い方

1. `recipe.html` をブラウザで開く
2. フォームにレシピ名・材料・調味料・手順を入力して「保存」
3. 一覧からレシピを選択して印刷・編集・削除

## 技術スタック

| 技術 | 詳細 |
|------|------|
| HTML5 | セマンティックなマークアップ |
| CSS3 | レスポンシブ対応・印刷用メディアクエリ |
| JavaScript (ES6+) | バニラJS・LocalStorage API・Drag and Drop API・FileReader API |

## 工夫した点

- ライブラリやフレームワークを一切使わず、Web標準APIのみで実装
- `@media print` でA4横向き2段組の印刷レイアウトを実現
- `FileReader API` でJSONのエクスポート・インポートに対応し、データ移行を可能に
- ドラッグ＆ドロップAPIを使ったインタラクティブな並び替えを実装
